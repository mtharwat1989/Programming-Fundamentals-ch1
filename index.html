👨‍💻 البرنامج والأشخاص
Computer Programمجموعة أوامر وخطوات مرتّبة (الترتيب مهم) ينفذها الحاسوب كما كُتبت لأداء مهمة: يحدد ماذا يفعل وكيف
Programmerالشخص الذي يكتب البرامج (التعليمات) لينفذها الحاسوب
Userالشخص الذي يستخدم البرامج التي أنشأها المبرمج ويستفيد منها

🔄 المصدر والهدف والمترجمات
Source Program (Source Code)يكتبه المبرمج بلغة عالية المستوى (مثل Java) • مقروء للبشر • يتبع قواعد Syntax
Compilerيترجم البرنامج كاملًا أولًا
Interpreterيترجم وينفّذ سطرًا بسطر
Target Programناتج الترجمة (Bytecode أو Machine code) • قابل للتنفيذ من الآلة مباشرة أو عبر JVM
Source Program→Compiler / Interpreter→Machine code / Bytecode
Source = human readable → Target = machine executable

📊 البيانات ← المعلومات ← المعرفة
Dataحقائق خام غير معالجة • غالبًا تُستخدم كمدخلات
Processالخطوات (التعليمات) التي تحوّل البيانات إلى معلومات

Data→Process→Information→Knowledge

الفرع 6
🪜 مستويات لغات البرمجة
Machine Language (Low-level)0s و1s (ثنائية) • يصعب على البشر كتابتها وقراءتها • ينفذها CPU مباشرة • تعتمد على العتاد (Hardware dependent)
Assembly Language (Low-level)تستخدم Mnemonics (LOAD, STOR, MULT, ADD, SUB) • أسهل قراءة من لغة الآلة • تستخدم Registers وعناوين الذاكرة • تحتاج Assembler لترجمتها إلى لغة الآلة
High-Level Languageمصممة للبشر • كلمات شبيهة بالإنجليزية (if, while, print) • أسطر أقل • تحتاج Compiler أو Interpreter
ExamplesPascal • C++ • FORTRAN • PERL • Java • COBOL
Assembly→Assembler→Machine Language
